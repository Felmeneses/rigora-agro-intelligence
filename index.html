Conexão com o Pipeline Python e Arquitetura CitizenTech

Global Solution 2026

O Rigora Agro Intelligence foi estruturado de acordo com os pilares da CitizenTech: colocar a tecnologia e a análise de dados a serviço de quem mais precisa — os pequenos produtores rurais familiares e cafeicultores cooperados de Minas Gerais, que frequentemente não contam com equipes de ciência de dados ou softwares de alto custo.

Prontidão para Dados Reais: Este frontend MVP consome um contrato JSON de dados (ver arquivo js/data.js) perfeitamente compatível com o pipeline de extração, tratamento e consolidação desenvolvido em Python (notebooks com pandas/requests para as APIs públicas do IBGE SIDRA, Conab e INMET). Para atualizar os dados, basta plugar a saída estruturada do pipeline de dados.

* Não há atribuição de dados inventados às fontes oficiais. As fontes públicas estão devidamente marcadas como "Integração planejada" nesta versão de demonstração.
